# Hybrid CPU Governor Auto-Installer

this is a small project made so it can reduce the battery usage on laptops and can may make it snappier.. 
it divides half of cores as:-
On battery: The first half of the CPU cores use the schedutil governor, and the second half use the powersave governor. For example, on a 10 core CPU, the first 5 cores use schedutil and the other 5 use powersave. (Laptops only)
On Adapter (plugged in): The first half of the CPU cores use the Performance governor, and the second half use the Shedutil governor. For example, on a 10 core CPU, the first 5 cores will use Performance and the other 5 use Shedutil. works on both and can make your PC or laptop snappier
### i have seen or have known that Cpus prefer the first 5 cores if there no load on them so this script works on same principle
